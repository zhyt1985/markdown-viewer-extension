# 正式开发第五批：未命名文档与首次保存

日期：2026-11-05。分支：`feature/electron-desktop`。版本：`0.1.0-alpha.5`。

继续落实获批设计 V1.0 和 P2 日常编辑流程；冻结评审样稿未修改。当前仍为正式开发的 Alpha，25 项保留功能尚未全部验收。

## 新建、暂存与首次保存

- 开始页、文件菜单和 Ctrl+N 提供“新建文档”。新文档进入分栏并聚焦编辑器，显示“未命名 N.md”，各标签拥有独立、稳定的内部身份。
- 创建时先原子暂存，再展示新标签。暂存失败不创建缺少保护的标签，活动文档保持不变。
- 未命名文档不存在虚构源文件路径；空白和已编辑文档都可恢复。状态栏和提示区明确区分未命名暂存与真实文件保存，首次保存前提示相对资源的解析时机。
- “保存”及“另存为”都会让未命名文档选择保存位置。取消、非法扩展名、目标目录不存在或试图覆盖已打开源文件时，仍保留原身份与编辑内容。
- 首次保存默认 UTF-8、无 BOM、LF。空白文档也可以保存成真实的 0 字节 Markdown 文件。
- 保存成功后标签转换为实际文件，不额外创建重复标签；保留当前编辑器历史、光标与滚动状态，并将阅读记录迁移到文件身份。后续保存恢复磁盘版本冲突检查及原文件编码格式保护。
- 新增未命名文档不进入最近文件记录；首次保存后才记录真实本机路径。未命名文档禁用“重新载入磁盘”，避免把不存在的磁盘版本误作可恢复来源。
- 未命名文档不默认授权当前目录、工作区、应用目录或用户数据目录。相对本机资源在保存后基于目标目录解析；正文、公式、无外部资源的图表及单文档导出继续复用已有引擎。
- 导出仍固定在开始时的文档快照：导出中修改未命名稿并执行首次保存，不改变正在导出的原内容。
- 补齐提示区可见性：未命名保存位置、恢复状态及暂存失败详情可见；普通已保存文档不增加通用“未保存修改”横幅。

## 持久化与身份迁移

已有文件草稿继续采用 schemaVersion 1。新增未命名草稿采用 schemaVersion 2、kind=untitled，source/resourceRoot/workspaceRoot/diskVersion 均为 null；只包含内部 ID、受限名称、正文、默认编码格式与时间。校验拒绝在未命名记录中混入文件路径或资源根目录。

草稿数量/空间/正文上限仍为 32 条、128 MiB JSON 总量、每文档编码后 10 MiB。空白草稿也占一个暂存条目；显式关闭空白标签会移除它，正常窗口会话则保留未关闭的空白标签。

会话保持 version 1，并新增可选 untitledIds 与 activeDocumentId。旧会话仍可读取；恢复先加载有效文件与草稿，再按身份恢复活动标签。旧版本不能使用新未命名格式，但遇到未知草稿会保留文件并报告，不应把降级视为完整兼容恢复方案。

首次保存将随机的草稿 ID 转为真实文件的稳定路径 ID。主进程迁移阅读记录，编辑器迁移每文档状态，成功后清理旧草稿。对文件“另存为”也保留编辑状态并复制阅读记录；原文件阅读记录保留。草稿清理/阅读状态迁移失败单独提示，不将已经写入的文件误报为保存失败。保存成功但预览失败也分别表述。

文件写入、会话、阅读状态和草稿清理不是跨文件事务；在首次保存的提交步骤中异常退出，可能保留一份额外恢复草稿。该取舍优先保留文本，不承诺跨文件 exactly-once 提交，也不把进程恢复当作防磁盘损坏备份。

新增 `untitled-e2e.test.js` 九个子场景及父测试，加上 `draft-store.test.js` 一项未命名格式测试，共新增 11 个报告条目。真实 Electron 验证：

1. 开始页/键盘新建、多标签独立身份、无资源目录授权、最近文件不混入假路径。
2. 取消/非法路径/非法扩展名保留草稿；已打开源文件不被覆盖。
3. 首次保存迁移身份和阅读位置，撤销/重做仍有效，真实源文件正文及旧暂存清理正确。
4. 直接终止进程后，空白及已编辑标签按原身份恢复，活动标签恢复正确。
5. 放弃须明确选择，仅删除相应草稿；重启不会重新出现已放弃标签。
6. 暂存目录故障时新建失败，现有文件标签和正文不变。
7. 未编辑的空白文档能保存为实际空文件。
8. 未保存时不能读取相对资源；首次保存后图片从所选目录加载。
9. 原生保存流程中暂挂实际 DOCX 导出，首次保存并修改正文后，检查真实 OOXML 仍包含原快照而非后续正文。

单元测试覆盖空白/有正文记录的持久化、重开、删除和禁止路径/名称伪造；原有 schemaVersion 1 草稿单元测试保留。
