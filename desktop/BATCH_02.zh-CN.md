# 第二批开发记录：渲染与导出隔离、任务取消及故障恢复

分支：`prototype/electron-desktop`。依据 [本地个人版计划](DEVELOPMENT_PLAN.zh-CN.md)，继续 P1；本批未增加用户排除的功能。

## 实现结果

### 独立图表宿主

- 新增 `render-host.ts` / `render-host.html`，Mermaid 和共享图表引擎在独立隐藏 BrowserWindow 中执行，前台通过受限 IPC 请求图表结果。
- 图表宿主没有 preload、Node 集成、文件选择、存储或任意主机 API；只提供引擎所需的随包资源服务，保持外部请求阻断。
- `WindowWorker` 串行调度请求，限制排队数量为 100、单请求大小为 8 MiB、活动任务默认 60 秒超时；来源由主进程决定，不信任页面自报 owner。
- 每个请求校验文档 ID 和内容版本；切换文档会终止旧前台 owner 的活动/排队图表任务，旧结果不回填新文档。
- 超时、取消和进程故障会真正销毁相应宿主，拒绝当前任务；下一次请求按需创建新宿主。任务失败不会把坏结果缓存为成功。

### 独立导出任务

- 前台只提交格式和当前文档 ID/版本；主进程保存启动时的正文与设置快照，分配任务 ID，并为导出单独创建资源 grant。
- 每次导出创建独立的 `documd://export/export.html` 隐藏窗口；该窗口的 preload 仅能请求图表，不具备 open/save/state 等前台操作权限。
- DOCX 转换、图片检查和 PDF 排版都在导出宿主中进行。PDF 保存调用该宿主的 `printToPDF`；未新增系统打印入口。
- 导出期间可继续打开另一文件。前台旧 grant 被撤销，但活动导出自己的 grant 保留至终止，避免旧文档图片丢失；快照不随前台主题改变。
- 新增“取消导出”。取消会销毁活动导出宿主，并移除其图表任务；导出进程崩溃返回明确错误，之后可再导出。
- 从关闭保存对话框后开始计时，导出默认 120 秒总超时；正文、图表、图像完成后才能写入产物。
- 产物先写到目标同目录的独占临时文件，成功后 rename；失败/取消清除临时文件，保留已有目标。提交开始后取消返回 false，按实际提交结果显示保存状态。
- 本次会话打开过的源路径均受覆盖保护，防止切换文档后把产物保存到之前的源文件。

本批关键 E2E 证据：

1. 验证前台与图表宿主的 OS 进程 ID 不同；图表窗口不暴露 Node 和 desktop 桥。
2. 在真实图表宿主中挂起操作，再使其 renderer 实际崩溃；前台报告失败，重新打开原文档可恢复预览。
3. 比较导出前后的前台 DOM：DOCX/PDF 导出不重建或改写正在阅读的文档。
4. 暂停保存对话框返回，打开另一文档并修改主题，再恢复导出；产物仍包含原文档，且 OOXML 样式与原主题导出一致，新文档保持显示。
5. 在实际导出窗口挂起任务，分别点击取消和使 renderer 实际崩溃；已有目标字节保持不变，导出窗口消失，之后的新导出产生有效 DOCX，无遗留临时文件。
6. 保留此前本地路径、资源范围、公式/表格/图片、DOCX/PDF 真实产物、设置恢复、缺图失败与源文件保护检查。

独立 WindowWorker 测试覆盖真实计时器触发的超时销毁、不同 owner 的排队取消、崩溃和 dispose；不会只通过改变按钮状态断言“取消成功”。故障注入仅由测试过程操作 Electron 窗口，产品中没有专用测试后门。

证据文件仍写入 `test-results/desktop/development/` 和 `packaged/`。故意触发进程崩溃、请求拒绝与缺图会产生预期错误日志。

## 范围与剩余事项

- P1 已完成本批隔离/取消/恢复链路，尚未整体验收：通用 ElectronTransport/ServiceChannel 装配、进度事件、完整 i18n、持久化阅读状态和磁盘缓存仍需补齐。
- 目前冻结正文与设置，并保持原资源目录授权；图片等本地依赖的字节尚未形成不可变快照。导出过程中磁盘资源被外部程序修改的完整一致性需要后续资源版本检查/快照处理。
- 导出 120 秒总超时已有实现，但本批没有等待真实 120 秒验证；图表宿主超时由较短独立测试验证。队列仍为 FIFO，并发/内存预算尚未完成性能验收。
- 阻塞中的原生系统保存对话框应通过系统“取消”关闭；应用“取消导出”按钮主要覆盖对话框完成后的后台任务。原生对话框人工交互仍未验收。
- 仍限当前本地 Markdown 预览和 DOCX/PDF 主流程；全部图表引擎、Slidev、HTML/XLSX 等保留功能及被排除能力的共享引擎开关尚未整体完成。
- 没有修改共享引擎源码；本批未重跑完整浏览器、移动、VS Code 或 fibjs 测试。亦未进行干净 Windows 目标机验收。

下一批继续补齐 P1 平台服务与状态合同，再进入 P2 工作区/编辑。25 项保留功能继续按实际证据标记为进行中或未开始，不作完整版完成声明。
