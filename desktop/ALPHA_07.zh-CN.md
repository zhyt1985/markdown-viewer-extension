# 正式开发第七批：常驻章节目录

日期：2026-11-06。版本：`0.1.0-alpha.7`。分支：`feature/electron-desktop`。

## 本批行为

- 活动栏新增“章节目录”，与文件、检索、最近打开共用左侧导航空间，正文目录仍在右侧。
- SUMMARY 嵌套列表显示为常驻章节列表；支持非链接分组、链接文本中的强调/行内文本及引用式链接。当前文件标记为 aria-current，提供上一章/下一章及刷新目录按钮。
- 章节路径以当前授权根下的 SUMMARY.md 所在目录为基址；因此从子目录章节切换时仍能找到同一本目录中的其他章节。
- 切换复用原有导航、草稿同步和阅读位置保存。目录项不直接作为浏览器 URL 打开，主进程继续校验当前文档、目录范围标识和实际规范路径；范围不匹配须刷新，不能借旧侧栏扩权。
- 刷新先同步编辑器，再读取已打开 SUMMARY 的未保存草稿或磁盘版本。刷新不保存源文件。缺失或不可用目录清空章节列表并提示，活动正文及编辑稿保留。
- 输入上限 256 KiB，列表最多 500 项及 24 个结构层级，达到展示上限会提示；标签作为纯文本插入，不执行 SUMMARY 中的 HTML。

使用已安装的 unified/remark-parse 解析 Markdown AST，通过现有浏览器构建打包；没有新增依赖，也没有将原始 HTML 插入应用导航。冻结评审样稿没有修改。没有增加整书导出、远程资源或宿主互通。
