# 正式开发第六批：本地阅读导航

日期：2026-11-06。分支：`feature/electron-desktop`。版本：`0.1.0-alpha.6`。

## 本批功能

- 工具栏前进/后退按钮及 Alt+左右方向键，恢复各次访问的阅读位置。访问记录最多 100 条，仅在当前窗口会话内保留；关闭标签后清除其访问条目，不借历史重新授权已关闭文件。
- 本地相对 Markdown 链接与跨文档锚点。支持中文、空格、百分号和井号的单次 URI 解码；以当前授权目录为边界验证规范路径，拒绝绝对路径、URL、查询参数、非 Markdown 类型、越界及指向范围外的目录链接。
- 跳转前继续同步草稿、保存阅读状态；历史展示的是当前文档内容，不回滚编辑版本。首次保存时更新已有访问记录的文档身份。
- “更多文档操作 → 打开 SUMMARY 目录”读取当前授权根目录下的 SUMMARY.md，使用既有 Markdown 引擎显示嵌套列表，点击章节沿用本地链接校验并复用标签。
- 锚点只查找正文内部的 ID，不定位应用控件；缺失锚点提示文档已打开但目标不存在。空锚点回到文档顶部。
- 无效、缺失和越界目标不替换活动文档，不增加无效历史。尚未更新的预览不能触发链接跳转。未命名文档须先保存才能解析相对文件链接。

没有改动冻结设计样稿。前进/后退并入既有工具栏，SUMMARY 入口放入文档菜单；没有新增整书导出、远程资源或宿主互通能力。

## 边界和后续

SUMMARY 当前是可交互的目录文档，尚无独立常驻书籍侧栏、自动前后章控件或所有目录语法变体的验收。直接打开文件的资源根为其所在目录，工作区文档的根为已授权工作区；不向父目录扩权寻找目录文件。访问历史不跨窗口重启恢复，关闭活动标签后可从剩余标签重新建立导航起点，超出当前支持范围的文件类型继续拒绝。

其他 P2/P3 项目、完整主题/设置、批注、图表、其他保留导出与目标 Windows 验收继续按开发计划推进。未新增依赖，既有构建依赖审计事项未处理；未重跑其他平台全套回归，尚未完成人工 Office、高 DPI、全部输入法与干净机器验收。

运行入口仍为 `dist/desktop/packages/documd-desktop-win32-x64/documd-desktop.exe`，需保留整个便携目录。未执行 Git 提交。
