# 第三批开发记录：平台服务、阅读恢复、磁盘缓存与语言加载

分支：`prototype/electron-desktop`。按 [本地个人版计划](DEVELOPMENT_PLAN.zh-CN.md) 继续 P1，不扩展用户已排除的功能。

## 已实现

### 统一服务通道

- 新增 ElectronTransport，把受限 preload 的请求/事件接入共享 ServiceChannel，复用现有请求关联、超时与错误响应合同。
- 设置、缓存和阅读状态接入共享 StorageService / CacheService / FileStateService；`platform.message` 支持有类型的宿主请求及事件订阅，不再是空实现。
- 主进程只受理已实现的服务类型，校验调用窗口/主 frame、信封、大小和参数；未知类型明确失败，不暴露 shell 或任意路径操作。
- 继续保留旧 state 桥兼容入口，但也转交同一服务校验。设置键、数据类型、枚举和数值范围来自共享 settings-schema，语言值来自已登记 locale；不另写一套默认设置。
- 设置写入在当前前台适配实例中串行化，避免并发修改两个字段时客户端的读改写互相覆盖；设置变更会产生 SETTINGS_CHANGED 事件。

### 阅读状态落盘和恢复

- 以真实路径计算的稳定 DocumentId 作为存储键，与临时资源 token 分离。
- 阅读状态通过主进程原子 mutate 合并，读取/写入仅允许本次会话已经打开的文档 ID，拒绝任意路径字符串或非法字段/数值。
- 滚动保存去抖，切换文件前等待保存；正常关闭窗口时等待阅读状态 flush，最多等待 2 秒。
- 重启应用后，**手动重新打开同一文件**即可恢复滚动位置。当前实现为像素位置，不是源行锚定；没有声称已实现自动重开文件、完整会话恢复、缩放/TOC/布局 UI。

### 磁盘缓存

- 缓存在 userData/cache/render，采用哈希文件名与独立写队列；默认最多 100 条、总计 64 MiB、单条值最多 8 MiB。
- 写入先生成临时文件再替换；有 LRU 淘汰，读取时检测版本不符、损坏、异常大小和非普通文件，将其作为 miss 清理。
- 缓存命名空间包含图表宿主构建、样式和 Electron 版本的指纹；自动图表 key 包含类型、源代码、主题配置与文档内容版本。
- 自动结果复用仅启用于未发现资源引用的 Mermaid / DOT 文本图表；其他引擎继续实际渲染，避免在缺少依赖版本跟踪时缓存不可靠结果。明显失败结果不写入自动缓存。
- 新增缓存信息/清理按钮。统计不返回缓存正文；清理只影响缓存，不删除设置、阅读状态或其他个人数据。

### 本地语言资源

- 构建复制全部 28 种已登记 locale；加载英文 fallback、显式语言与系统语言匹配，并通过共享 BaseI18nService 处理消息查找。
- 新增语言下拉框，选择结果持久化；打开、DOCX、取消、缓存等现有标签使用已有翻译，核心 Viewer 接收实际 translator。
- 本批完成语言服务和部分界面标签接线。部分桌面状态文案仍为中文，PDF 标签等新文案及完整 UI 翻译在 P3 统一处理，不能把“全部语言文件可加载”当成“每个界面都已翻译完成”。
- 视觉复查同时补齐了预览中的表格/图片/图表布局 class，避免已保存的图片对齐设置只存在于配置中却没有反映到预览；增加实际预览检查。

21 个报告条目包括原有 11 个 E2E 子测试及父测试、1 个完整重启测试、8 个独立测试，并非 21 项产品功能完整验收。

新增的真实重启测试没有只做网页 reload：

1. 在一个新 profile 启动实际 EXE，打开足够长的本地文档，加载 Mermaid；确认缓存有实际图表结果。
2. 逐个读取 28 个语言文件；验证 PING、未知服务拒绝、设置变更事件及并发设置保存；切换简体中文。
3. 滚动到文中指定位置，通过真实窗口关闭触发 flush，等待整个应用进程退出。
4. 用相同 profile 再启动，手动重新打开同一文件；验证语言及滚动位置恢复，缓存探针仍存在。
5. 确认未创建图表渲染窗口，证明未变文档复用了持久结果，而非仅成功读取一个测试写入值。
6. 点击清理缓存，验证统计归零、设置仍保留。独立服务测试另验证清理不会丢失阅读状态。

独立测试还覆盖跨存储实例读取、LRU、容量拒绝、版本变化、损坏缓存、路径型 cache key 安全映射、并发阅读字段合并、非法范围/设置/文档访问拒绝。前两批的隔离、取消、崩溃恢复、快照与实际导出回归继续通过。

打包脚本新增可选的本地 ZIP 入口，路径由构建环境显式提供，未写入开发者绝对路径。摘要不匹配立即失败，不修改第三方包或跳过验证；应用运行时仍无需网络。
