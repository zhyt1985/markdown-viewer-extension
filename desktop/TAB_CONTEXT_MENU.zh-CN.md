# 标签页右键关闭菜单

日期：2026-11-07。版本：`0.1.0-alpha.13`。分支：`feature/electron-desktop`。

## 行为

标签页右键菜单提供“关闭当前文件”“关闭其他文件”“关闭全部文件”，复用现有应用菜单样式。“当前”指右键点击的标签；右键打开菜单不切换当前正文。“关闭其他”保留点击的标签，必要时将其设为活动文档。只有一张标签时禁用“关闭其他”。

菜单支持 Shift+F10/菜单键、上下方向键、Home/End、Enter、Esc 和 Tab 退出；点击外部、窗口失焦、标签栏滚动或窗口大小改变后收起，位置限制在窗口内。关闭后焦点回到保留的标签或欢迎页入口。

## 未保存文档与批量关闭

沿用现有“取消 / 放弃修改”确认。操作先同步当前编辑器的最新输入，主进程确定整个关闭范围，再一次性确认其中的未保存文件，并列出文件名。取消时不关闭任何标签，包括干净标签。“关闭其他”不会把保留标签的编辑稿计入放弃范围。

确认后才清理所关闭标签的草稿、未命名阅读状态及文件监控，并更新会话。关闭全部后显示欢迎页；重载不恢复已经关闭的标签。源文件、工作区目录和已有导出快照按原逻辑保留。

标签叉号和右键菜单共用关闭实现。主进程校验操作类型和点击标签身份；失效标签不能作为关闭全部/其他的依据。
