# 大文档滚动性能修复

日期：2026-11-06。版本：`0.1.0-alpha.11`。分支：`feature/electron-desktop`。

## 原文档与原因

使用用户指定的接口设计 Markdown 原文件只读测试，大小 377,523 字节。Alpha 10 实际 EXE 渲染后包含 14,748 个 DOM 元素、915 个内容块、135 张表格、132 个代码块、两张 Mermaid 图，阅读区内容约 197,465 px 高。

发现两类不同的开销：

1. **纯阅读模式的 GPU 尖峰**：两张图的 PNG 原始尺寸分别为 4860×5372、5224×7056，正文中却只显示约 717 px 宽。约 6,296 万源像素在首次进入视口时需要解码/上传；Chromium trace 捕获到约 199 ms 的 `CrGpuMain` 任务及约 36 ms 的图像上传任务。滚动帧延迟集中在进入第一张图的位置，而非普通正文的 JavaScript 长任务。
2. **分栏模式的持续脚本开销**：源码定位每次扫描全部 915 个块并重复读取 DOM 几何；50 次查询读取 91,550 次几何。同步状态判断还会反复将 CodeMirror 文档转成全文字符串，并对全文换行格式做归一化比较。

## 变更

- 屏幕中的超大 PNG 图表按正文最大宽度及当前 DPI 生成显示副本，保留长宽比及页面几何。本次 2 倍 DPI 下副本为 1448×1601、1448×1956，总像素约 515 万，比源图少约 92%。只缩小屏幕位图；原始 PNG 通过 `originalImageSource()` 保留，SVG 注册表及独立 DOCX/PDF 导出主机仍使用原始资源。页面切换/清空时释放 Blob URL。
- 源码块在流式渲染各批次与渲染结束时建立元素/行号索引，按实际位置二分查找，单次仅读取约 12 次几何。没有缓存容易因重排失效的绝对像素位置，窗口改变后仍读取实时位置。图表尚在异步渲染时，已经显示的正文仍可定位。
- 编辑器提供只随内容或文档切换变化的修订号；未修改时复用全文比较结果，继续保证输入、撤销、重做、切换与草稿同步后立即更新脏状态。

没有引入估算高度的文档虚拟化，不跳过正文、表格或源码同步。实验中的整体块隔离未纳入产品代码。

## 测量与回归

性能探针：`desktop/bench/scroll-performance.js`。正常 Node.js + Playwright 驱动真实 Electron，使用隔离配置，对原文件做 SHA-256 前后校验；CPU profile、Chromium trace 与统计只存入忽略目录 `test-results/desktop/performance/`。

同机首轮对比：50 次源码定位从约 122 ms / 91,550 次几何读取降到约 0.5–0.7 ms / 600 次读取。最终 Alpha 11 实际 EXE 的 240 帧分栏滚动脚本时间约 0.223 s，对比 Alpha 10 的约 1.105 s 下降约 80%。原文档纯阅读测试的最慢帧从约 183–300 ms 降至约 17 ms；打包版普通采样和独立 trace 采样均未出现超过 34 ms 的帧。相同时间线的 GPU 最长任务从 198.536 ms 降至 14.984 ms，图像上传最长任务从 36.298 ms 降至 3.319 ms。原文件 SHA-256 前后相同。

最终测量位于 `test-results/desktop/performance/alpha11-packaged/results.json` 与 `alpha11-reading-trace/reading.trace.json`；Alpha 10 对照位于 `alpha10-baseline/`、`alpha10-reading-trace/`。两版 DOM 数量、文档高度及两图显示尺寸/位置一致。本次未承诺缩短首次打开时间，位图生成发生在加载阶段。

上述是本机受控滚动测量，包含中途跳转后继续滚入图表，不等于所有机器、输入设备及后台负载下的帧率保证。性能测试不以不稳定的墙钟阈值作为回归门禁；新增 E2E 检查二分查询与全量参考结果一致、读取次数随对数增长、未修改时不再读取全文、修改后立即标脏、原图保留及 Blob 释放。既有流式预览和同步行为继续由真实窗口测试覆盖。

完整开发入口与最终打包 EXE 回归均 **117/117** 通过，无失败或跳过。项目源码类型检查 0 错误，既有 vendor 源码分发诊断 297 条单独报告。版本、八项关键运行文件与构建哈希一致，冻结设计样稿哈希未变，`git diff --check` 通过。已查看原文档图表显示副本，图像长宽比和页面位置与原版一致。
