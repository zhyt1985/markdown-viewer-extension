# 第六批开发记录：基础编辑、文件监听与保存冲突

日期：2026-11-05。分支：`prototype/electron-desktop`。
继续 [本地个人版计划](DEVELOPMENT_PLAN.zh-CN.md) 的 P2，未将整个阶段或完整版标记完成。

## 已实现

- 本地 Markdown 源码编辑与分栏预览；“编辑”切换源码面板，“更新预览”使用当前编辑稿重新渲染。
- 编辑稿通过受限 IPC 同步到主进程内存，切换标签后仍保留；按稳定文档 ID、递增 revision 校验，过期更新/保存被拒绝。编辑不自动写入源文件。
- 未保存标签显示 `*`，磁盘变化显示 `↻`。未更新预览时禁用导出，避免界面展示内容与导出入口绑定版本不一致；更新后可以导出未保存编辑稿。
- “保存”仅写当前源文件；“另存为”由系统对话框选择 Markdown 目标，成功后用新路径替换当前标签，原文件保留。拒绝另存覆盖已打开过的源路径，当前源文件应使用“保存”。取消或失败保留编辑稿。
- 保存记录并保留 UTF-8 BOM 及 CRLF/LF 换行风格；读取和写入均限制 10 MiB。无效 UTF-8 明确拒绝，避免编辑保存造成替换字符损失；失败不会替换当前活动文档或增加隐藏标签。
- 新增 Ctrl+S 保存、Ctrl+Shift+S 另存、Ctrl+R 重新载入。重新载入、关闭标签、移除工作区或关闭窗口涉及未保存修改时，弹出默认取消的原生确认；取消后保留编辑。窗口关闭先等待前台编辑稿同步和阅读状态保存，超时则取消关闭。
- 约每 750ms 检查已加载源文件的大小、修改/创建时间和文件身份。未编辑的活动文档自动刷新并恢复阅读位置；可以取消勾选“自动刷新”暂停，恢复勾选后处理待刷新内容。
- 外部变化不会覆盖未保存编辑稿；删除、替换文件等情况可见提示。源文件删除后，编辑稿仍可通过另存为恢复。
- 关闭标签移除监听记录，关闭窗口释放计时器；同一状态不重复发事件。
- 进行中的导出继续使用启动时的文档/设置快照，后续编辑或预览不会改变已启动任务的内容。

## 保存与路径合同

1. 主进程持有原始磁盘内容哈希和格式信息；前台不能自行传入保存路径或重置磁盘基线。
2. 写入前重新校验 canonical 授权根、目录和文件路径；原目录被 junction 替换或文件变成链接时拒绝写入。
3. 对比磁盘字节哈希。已修改/删除的源文件报告冲突，不提供强制覆盖按钮；可先另存编辑稿，再重新载入外部版本。
4. 同目录创建独占临时文件，写入并 sync；替换前再次校验路径和磁盘哈希，随后 rename。取消/失败清理本次临时文件。
5. 另存的目标父目录来自原生选择并规范化；已有目标取得基线后也执行二次校验，不绕过源文件覆盖保护。

这是乐观并发检查，不是操作系统级 compare-and-swap。另一个程序仍可能在最后一次校验与 rename 之间写入同一路径；本批未实现跨应用排他锁、源文件历史备份或完整 ACL/扩展属性保留。因此尚不能宣称覆盖所有并发写入及断电恢复情形。确认冲突时始终保留内存编辑稿，不自动选择覆盖外部内容。

实际覆盖：

1. 外部改写长文后自动更新正文，保持滚动位置；暂停后保留旧版，恢复勾选后加载新版。
2. 编辑稿不改源文件，标签往返仍保留；预览旧时不允许导出；拒绝旧 revision 保存；保存后实际文件保留 BOM/CRLF。
3. 外部修改后保存拒绝，编辑稿和磁盘正文各自保留；重新载入先取消再确认放弃，行为正确。
4. 另存取消、拒绝覆盖另一个已打开源文件、成功生成新文件并替换标签；原源文件保持原样。
5. 取消关闭 dirty 标签、工作区和实际主窗口后，编辑内容均保留；确认放弃关闭后才移除标签。
6. 导出启动后继续编辑和预览，实际生成 PDF 的文本仍是导出前版本；源 Markdown 未被导出过程改写。
7. 删除 dirty 源文件，保存拒绝但另存成功；替换所选目录为 junction 后，保存不会写入根外同名文件，编辑稿仍能恢复到其他目标。
8. 无效 UTF-8 打开失败后，活动文档、注册标签和编辑器内容保持原样。
9. 单元测试在临时文件已落盘后、最终校验前注入外部修改，验证拒绝 rename 并清理临时文件；另覆盖编码、路径、删除、文件替换、重新创建与监听释放。
10. 既有离线渲染、真实 DOCX/PDF、进程隔离/崩溃恢复、缓存/语言、会话、检索和工作区测试继续通过。

## 发现并修复

- 磁盘变化提示插入页面时会改变正文位置；提示区域改为固定高度并可内部滚动，长文自动刷新和暂停/恢复均检查原位置。
- 源文件在保存前删除时，最初暴露底层 ENOENT；现在统一为保存冲突，提示另存恢复。
- 严格 UTF-8 校验引入了新的打开失败分支：改为先成功激活首个文档再注册其余多选标签，失败不留下前台未知的额外标签。

## 边界与后续

- **编辑稿只保留在内存中，不是自动恢复文件。** 正常退出前可取消关闭并先保存；进程崩溃、强制结束或断电仍可能丢失未保存内容。异常草稿恢复、未命名新建文件仍待实现。
- 目前为 textarea 基础编辑入口；CodeMirror 方案、查找替换、行号、持久撤销/重做、双向滚动定位及编辑模式持久化仍未完成，不声称 F08 整项验收。
- 监听只覆盖已实际加载的源文件，不监控图片/图表依赖、所有未展开目录和检索结果。暂停开关仅控制本次窗口的自动刷新，尚未持久化。
- 监控使用轮询和元数据变化检测，没有完成 32 个大文档下的性能基准；不能保证发现外部程序刻意还原全部元数据的修改。保存仍独立计算内容哈希。
- 保存不做三方合并，不支持其他编码的选择重开；只读、磁盘满、目标占用和更多写入竞态需继续专项验收。
- P2 仍需拖放、文件关联/单实例、普通文档链接、前进后退、当前文件定位、检索实时进度及大目录基准。
- 后续继续保留范围内的 SUMMARY、多格式阅读、批注、主题/设置、全部图表及导出格式，不恢复已排除的功能。
